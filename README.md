# Tasqueue 

A quest-based To-Do app inspired by RPGs.

## About

Tasqueue turns everyday tasks into RPG-style quests. Complete subtasks to attack monsters and make progress on your quests.

## Features

- RPG-inspired task management
- Quest and subtask tracking
- Monster HP system linked to task completion
- Fantasy-themed UI
